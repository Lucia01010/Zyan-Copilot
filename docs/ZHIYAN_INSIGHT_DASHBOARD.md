# 知妍·洞察 Dashboard

## M17.1 视觉与数据说明

看板使用 `/api/risks` 返回的真实风险事件做只读聚合，不生成新的业务记录。

- **风险等级分布**：按 `level` 聚合，环形图和图例可筛选列表。
- **主要风险来源**：按风险规则的 `category` 聚合，点击条形可筛选。
- **风险趋势**：优先使用风险事件的 `observed_at`；该字段来自关联客户最新客服聊天的 `sent_at`，表示风险关联服务记录时间，不冒充独立的数据库创建时间。按最近 14 个有记录日期统计。
- **风险处理进度**：按 `status` 聚合，点击状态可筛选列表。
- **重点风险客户 Top 5**：按高危和紧急事件中的 `buyer_nickname` 聚合，点击客户可筛选。

顶部 KPI 与风险列表使用同一批 `/api/risks` 数据，因此总数和筛选结果可以相互核对。没有时间字段时趋势图显示“当前暂无足够时间序列数据”；没有风险事件时各图表显示空态。

图表是总览层，风险列表是执行层，点击列表仍会加载原有风险详情、证据、服务轨迹和状态更新。
