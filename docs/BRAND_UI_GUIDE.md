# 知妍 AI Brand UI Guide

## 品牌定位

知妍 AI（Zhiyan AI）是面向美妆客服场景的智能接待与风险洞察 Copilot。Mascot 是专业助手的识别与状态反馈，不是虚拟宠物或聊天机器人。

## 组件与使用

- `BrandIcon`：24/32/40/48px，用于页面 Header、知妍·伴答标题、风险详情和回复标题。
- `ZhiyanMascot`：72–120px，用于插件空状态、欢迎与分析等待；不占用客户消息和风险数据主区域。
- `AgentStatusMascot`：32px，用于 ready/running/completed 状态；running 仅使用 3 秒呼吸浮动。

## 视觉规范

- Primary Violet：用于品牌文字、主按钮和风险辅助强调。
- Secondary Blue：来自 Logo 背景，用于轻量状态高亮。
- White：用于团子主体和 SaaS 卡片背景。
- 使用圆角卡片、柔和阴影和简洁线性层级；避免大面积渐变、游戏化动画和调试 JSON。

## 产品边界

模拟千牛 Host 保持客户列表与聊天效率；知妍 mascot 只属于知妍·伴答插件和知妍·洞察风险分析，不覆盖整个工作台。

## 状态文案

- 空状态：知妍已准备好
- 分析中：知妍正在分析当前会话…
- 回复：知妍生成建议回复
- 模式：LIVE QWEN MODE / DEMO CACHED MODE
