# 知妍 AI 品牌指南

## 主品牌

- 中文：知妍 AI
- 英文：Zhiyan AI
- 英文产品描述：Zhiyan Beauty Copilot
- 产品定位：面向美妆客服场景的智能接待与风险洞察 Copilot。
- 一句话介绍：知妍 AI 通过大模型 Agent 理解消费者需求，结合订单、物流、历史服务等业务信息，为客服提供实时辅助，并帮助企业发现和跟踪服务风险。

## 产品模块

| 中文名称 | 英文名称 | 定位 |
| --- | --- | --- |
| 知妍·伴答 | Zhiyan Copilot | 模拟千牛工作台中的智能接待辅助插件 |
| 知妍·洞察 | Zhiyan Insight Dashboard | 客户服务风险预警与跟踪中心 |
| 知妍·智核 | Zhiyan Intelligence Core | Agent Runtime、业务 Tools、证据 grounding、Hybrid Risk 和回复生成 |

## UI 用词

- 顶部品牌显示：`知妍 AI` / `Zhiyan Beauty Copilot`。
- 宿主显示：`模拟千牛客服工作台`。
- 插件显示：`知妍·伴答` / `智能接待辅助插件`。
- 看板显示：`知妍·洞察` / `风险预警与跟踪中心`。
- 建议回复显示：`智能回复建议`，辅助说明使用 `知妍生成`。
- 风险详情使用：`知妍风险分析`、`关键依据`、`服务轨迹`、`处理建议`。

## 禁用用词

不要在用户可见文案中使用 `Beauty Care Agent`、`Beauty Customer Agent`、`Generic Assistant` 或把产品描述为普通客服机器人。`suggested_reply` 等字段名属于 API/数据契约，可保留在代码和技术文档中。

## 叙事边界

左侧和中间区域是模拟千牛客服工作台宿主，右侧是知妍·伴答插件；知妍·洞察负责风险跟踪；知妍·智核是后端能力名称，不直接暴露为用户界面技术名词。
