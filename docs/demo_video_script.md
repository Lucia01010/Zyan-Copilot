# 知妍 Agent 演示视频 · 分镜与字幕口播稿

- 总时长：约 4 分 40 秒
- 形式：真实界面录屏 + 口播（参考 B 站 Agent 案例演示视频风格）
- 录制前准备：启动服务（`scripts/run_service.cmd`，9000 端口），浏览器窗口化 1920×1080，缩放 100%，提前打开 `/workbench` 与 `/risk-dashboard` 两个标签页
- 建议录制顺序：按幕顺序一遍过；每幕操作之间停顿 1–2 秒，方便后期剪辑对齐口播

---

## 片头（00:00–00:12）

**画面**：黑场渐入 → 知妍云朵精灵 Logo +「知妍 Zhiyan Beauty Copilot」品牌字样 → 一行定位语「懂业务 · 能行动 · 可追责的美妆电商 AI 客服」

**口播**：
> 美妆客服每天要面对成百上千条咨询：回复慢、风险漏判、经验难沉淀。
> 这是「知妍」——一个懂业务、能行动、可追责的美妆电商 AI 客服智能体。
> 接下来用四分钟，看它如何工作。

---

## 第一幕 · 工作台总览（00:12–00:45）

**画面**：切入 `/workbench` 全景，鼠标缓慢扫过三栏：左侧会话列表 → 中间对话区 → 右侧插件面板

**口播**：
> 这是模拟千牛的客服工作台，三栏布局。
> 左侧是接入真实业务数据库的会话列表，每条会话都带有实时计算的风险标签；
> 中间是客户与客服的完整历史对话；
> 右侧，就是知妍的智能接待辅助插件——整个演示的主角。

---

## 第二幕 · 客户洞察与真实数据（00:45–01:15）

**画面**：选中会话 S00082（不良反应 / 历史服务场景）；鼠标依次划过「客户洞察」卡的当前诉求 / 情绪 / 风险三格；再下移划过订单商品卡与工单卡

**口播**：
> 会话选中后，知妍先自动完成理解：
> 当前诉求、客户情绪、风险等级，全部用中文呈现，客服一眼掌握全局。
> 下方的订单商品和关联工单，全部来自业务数据库的真实记录——
> 知妍有一个铁律：业务事实必须来自工具查询，绝不允许模型编造。

---

## 第三幕 · Agent 自动分析（01:15–01:55）

**画面**：右侧对话框展示「知妍正在分析当前会话…」加载态 → 依次输出三条消息：状况总结气泡 → 建议行动按钮组（如「查看订单消息」）→ 建议回复气泡（带「知妍 · AI生成」标签）

**口播**：
> 同时，知妍 Agent 在后台启动完整分析流程：
> 组装上下文、检索对话记忆、规划行动、选择工具。
> 十几秒后，它产出三样东西——
> 一段历史对话与状况总结；
> 一组可以一键执行的建议行动，比如直接调出这个客户的订单消息；
> 还有一条拿来就能用的建议回复。
> 注意：每一条内容，背后都有工具返回的真实数据作为依据。

---

## 第四幕 · 气泡操作、自由问答与附件（01:55–02:30）

**画面**：① hover 客服气泡 → 复制/编辑图标浮现；② hover 知妍气泡 → 复制/重试/赞/踩图标；③ 点击「查看订单消息」快捷行动 → 结果气泡返回；④ 输入框提问「这款精华孕妇可以用吗」→ 知妍基于知识库回答；⑤ 点击「+」上传一张图片 → 缩略图出现在对话框

**口播**：
> 每条消息都支持复制、编辑、重试和点赞点踩——人工反馈会持续沉淀。
> 建议行动可以一键执行，结果直接回到对话里。
> 不满足于建议？直接向知妍自由提问：
> 涉及订单、物流、退款，它调用业务工具查真实数据；
> 涉及产品成分、售后规则，它走知识库检索，答案标注来源。
> 图片和文件也能真实上传，随对话留存。

---

## 第五幕 · 回复闭环（02:30–02:50）

**画面**：点击建议回复里的「复制到回复框」→ 文本写入回复编辑器 → 微调一个词 → 点击右下角「发送」；顺带点击右上角全屏图标，展示全屏沉浸模式后退出

**口播**：
> 一键把建议写入回复编辑器，修改后直接发送给消费者——
> 从客户洞察到回复 outbound，整个过程十秒闭环。
> 需要专注时，插件还能一键全屏。

---

## 第六幕 · 风险看板总览（02:50–03:30）

**画面**：切换到 `/risk-dashboard`；全景停留 2 秒 → 鼠标依次划过四张指标卡 → 趋势折线图（指出纵坐标刻度）→ 点击「主要风险来源」某个条形 → 列表自动筛选 → 再点「清除筛选」

**口播**：
> 客服侧之外，管理者打开「知妍·洞察」风险看板。
> 风险总数、高风险、待跟进，四张指标卡一目了然；
> 趋势折线图反映风险随时间的变化；
> 主要风险来源支持点击下钻——比如重点客诉，列表立刻筛出对应事件；
> 事件列表按最后聊天时间排序，随时掌握最新动态。

---

## 第七幕 · 风险详情与处理闭环（03:30–03:55）

**画面**：点击任意事件「查看详情」→ 弹窗展开；滚动展示：风险原因 → 关键依据（工单号 / 命中信号 / 12315 热线等中文标签）→ 订单 / 工单 → 服务轨迹（滚动到底）→ 修改「当前状态」为「处理中」→ 填写备注 → 点击「保存状态」

**口播**：
> 点开任意一条风险：风险原因、结构化的关键依据、关联订单与工单、完整服务轨迹，逐层展开，证据链清清楚楚。
> 处理状态和备注保存后实时同步看板——每一条风险的来龙去脉和处置结果，全程可审计。

**画面**：切至架构示意页（静态图卡或简单动画）：Agent 流程条（Input → Context → Memory → Planning → Tool/RAG → Response → Grounding Check）→ 四项评估指标数字卡

**口播**：
> 支撑这一切的，是一套完整的 Agent 工程流程：

> 最后必须经过「事实核查」——没有依据的话，宁可诚实说不知道。
> 系统还建立了可量化的评估体系：工具调用准确率、检索准确率、幻觉率、记忆准确率，四个维度持续追踪。
